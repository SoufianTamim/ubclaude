# Troubleshooting

**The panel says Claude Code isn't installed or signed in**
Install Claude Code and sign in with your Claude Pro or Max account. UBClaude's welcome screen has a button for each step and reconnects by itself.

**"Your login expired"**
Click **Open Claude Code** in UBClaude. Claude Code renews the login when it starts, and UBClaude reconnects.

**The numbers don't update**
Click the refresh button (or press ⌘R in the panel). If Anthropic is rate-limiting requests, UBClaude waits a little and tries again.

**No notifications**
Settings → Send test notification. If nothing appears, allow notifications for UBClaude in System Settings → Notifications.

**"This key is already used on 3 Macs"**
Deactivate the key on a Mac you no longer use (Settings → Licence), or email us.

**"This key wasn't found"**
Copy the key exactly from your email, or use the one-click button in the email.

**macOS won't open the app**
See [Installation → macOS can't check this app](installation.md).

Still stuck? Email **contact@usagebarclaude.com** with a screenshot.
