# Privacy

- **No account.** UBClaude uses the Claude Code login already on your Mac.
- **Your usage** is read from Anthropic and shown only on your Mac.
- **Token stats** are counted locally from Claude Code's log files.
- **Licence checks** send your activation key and an anonymous hash of your Mac's ID (never the ID itself).
- **The website** keeps anonymous visit statistics only (no cookies).

Full policy: [usagebarclaude.com/privacy](https://usagebarclaude.com/privacy)
