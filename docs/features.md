# Features

| Feature | What it does |
|---|---|
| 5-hour session limit | Live percentage of your rolling 5-hour window and when it resets |
| Weekly limits | Your weekly limit, plus per-model weekly limits on plans that have them |
| Monthly extra usage | Credit spent this month, if you turned on extra usage |
| Reset countdowns | A live countdown for every limit |
| Pace forecast | "At this pace you'll hit the limit in 1h 20m" |
| Alerts | Notifications at 50%, 75% and 90%, and when your session resets |
| Tokens tab | Today, 7 days, this month, a 14-day chart and a per-model breakdown, counted locally |
| Menu bar options | Session %, session + weekly, or icon only |
| Launch at login | Starts with your Mac |
| Light and dark mode | Follows macOS |
