# Getting started

1. **Open UBClaude.** The ring icon appears in your menu bar.
2. **Connect to Claude Code.** UBClaude uses the login Claude Code already saved on your Mac.
   - If Claude Code isn't installed or signed in, the welcome screen walks you through it in one click.
   - UBClaude connects by itself as soon as you're signed in, no restart needed.
3. **Click the ring** to open the panel:
   - **Limits**: your 5-hour session and weekly limits, reset countdowns and pace forecast.
   - **Tokens**: tokens used today, in the last 7 days and this month, per model.
   - **Settings**: what the menu bar shows, notifications, refresh interval, licence.

The menu bar shows your session percentage by default; the ring turns orange and then red as you get close to the limit.
