# FAQ

**Is UBClaude open source?**
No. UBClaude is proprietary software. This repository has the documentation and the official downloads.

**How does UBClaude get my usage?**
It reads the login Claude Code already stores in your macOS Keychain and asks Anthropic for your current limits. No account, no API key to paste.

**Does it send my data anywhere?**
No. The only usage request goes to Anthropic. Token stats are counted locally. The licence check sends only your key and an anonymous ID of your Mac.

**Does it work with Claude Pro and Max?**
Yes, both. It shows whatever limits your plan has.

**Does it count claude.ai usage?**
Your limit percentages include Claude Code and claude.ai. The Tokens tab counts Claude Code only.

**Intel Macs?**
Yes, UBClaude is universal (Apple Silicon and Intel), macOS 13 or later.

**How much does it cost?**
Free for 24 hours, then $9 once for a lifetime licence on up to 3 Macs, with all updates.

**Can I get a refund?**
Yes, within 14 days, no questions asked.

**Is UBClaude made by Anthropic?**
No. It's an independent app by North Stack Digital Ltd, not affiliated with Anthropic.
